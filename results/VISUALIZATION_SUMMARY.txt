📋 RECOMMANDATIONS PROCHAINES ÉTAPES
═══════════════════════════════════════════════════════════════════════════════

1. VALIDATION MANUELLE (2-3 heures)
   └─ Sélectionner 20-30 segments avec chevauchement < 90%
   └─ Vérifier manuellement la classification
   └─ Documenter les cas particuliers

2. RAFFINEMENT POTENTIEL
   └─ Si amélioration nécessaire:
      → Réentraîner CAMeL-BERT avec gold standard
      → Utiliser sequence tagging (BIO) plutôt que classification
      → Évaluer sur F1-score au niveau des limites

3. INTÉGRATION PRODUCTION
   └─ Combiner approches:
      → Baseline v4 pour pré-segmentation rapide
      → CAMeL-BERT pour classification fine
      → Gold standard pour supervision si entraînement additionnel

4. OPTIMISATION PERFORMANCES
   └─ Tester différents seuils de confiance CAMeL-BERT
   └─ Évaluer temps de traitement vs. qualité
   └─ Mettre en cache les prédictions pour corpus récurrents
