================================================================================
TROUBLESHOOTING
================================================================================

Problem: "File not found"
  → Files not on Drive
  → Check: data/processed/ has 3 required files
  → Fix: Upload files to Drive

Problem: "No GPU available"
  → Runtime not changed
  → Fix: Runtime → Change runtime type → T4 GPU

Problem: "CUDA out of memory"
  → Batch size too large
  → Fix: Stage 4, change per_device_train_batch_size=8
  → Rerun from Stage 4

Problem: Loss not decreasing
  → Data or model issue
  → Check: Stage 2 shows "Extracted 600+"?
  → Fix: Restart runtime, try learning_rate=1e-5

Problem: Inference hangs
  → Normal (can take 20+ min for full corpus)
  → Watch: Does output show "Processed XXX tokens"?
  → If yes: Let it continue. If no >2min: Restart runtime

Problem: Out of memory during Notebook 2
  → Too many predictions in memory
  → Fix: Restart runtime before opening Notebook 2
  → Runtime → Restart runtime

EMERGENCY PROCEDURES
================================================================================

If notebook hangs:
  1. Wait 2 minutes
  2. If still hanging, press: Ctrl+M (interrupt execution)
  3. If that doesn't work: Runtime → Interrupt execution
  4. Then: Runtime → Restart runtime
  5. Rerun from where you left off (data is saved)

If you get confused about where you are:
  1. Look at cell output numbers (higher = later in notebook)
  2. Look for [OK] or [ERROR] messages
  3. Check "Processed X/Y" messages for progress
  4. Read markdown headers above code

If results seem wrong:
  1. Check Notebook 1 Stage 5 loss did decrease

  3. Check Notebook 2 Stage 4 usable % (>60%?)
