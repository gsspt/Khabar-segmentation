1️⃣  ÉTAPE 1: OBTENIR LES POSITIONS DES ISNADS DU GOLD STANDARD
═══════════════════════════════════════════════════════════════════════════════

Fichier source: data/processed/kitab_uqala_al_majanin_annotated.json

Algorithm:
──────────
Pour chaque akhbar dans le JSON:
  1. Chercher le segment avec "type": "isnad"
  2. Extraire le texte exact de ce segment (le champ "text")
  3. Chercher ce texte dans le corpus brut (kitab_uqala_reference_corpus.txt)
  4. Si trouvé:
     - Enregistrer isnad_start = position du début dans corpus
     - Enregistrer isnad_end = isnad_start + longueur(texte isnad)

Résultat Attendu:
─────────────────
533 isnads avec positions exactes [char_start, char_end]

Exemple (Akhbar #2):
────────────────────
Gold JSON:
  akhbar[1].content.segments[0].type = "isnad"
  akhbar[1].content.segments[0].text = "أخبرنا أبو بكر محمد بن عبدالله الأرديشائي..."

Recherche dans corpus:
  text.find("أخبرنا أبو بكر محمد بن عبدالله الأرديشائي...")
  → Position 723 (char_start)
  → Position 987 (char_end = 723 + length)

Résultat enregistré:
  {akhbar_num: 2, isnad_start: 723, isnad_end: 987, length: 264}

3️⃣  ÉTAPE 3: CONVERTIR POSITIONS TOKEN → CARACTÈRE (CAMeL-BERT)
═══════════════════════════════════════════════════════════════════════════════

Fichier source: results/camelbert_kitab_uqala_raw_inference.json

Structure du fichier:
──────────────────────
{
  "inference_results": {
    "predictions": [0, 0, 1, 0, 1, ...],    ← array de 297,984 valeurs
    "probabilities": [0.02, 0.04, 0.97, ...] ← scores pour chaque token
  },
  "offsets": [[0,0], [0,1], [1,6], ...],    ← positions char [start, end] pour chaque token
  "tokens": ["[CLS]", "ك", "ت", ...]        ← tokens individuels
}

Algorithm:
──────────
Pour i = 0 à len(predictions)-1:
  1. Si predictions[i] == 1:  (c'est un boundary token)
       char_start = offsets[i][0]
       char_end = offsets[i][1]
       probability = probabilities[i]
       token = tokens[i]

       Enregistrer: {char_start, char_end, probability, token}

Résultat Attendu:
──────────────────
16,165 positions de boundary tokens avec:
- Position exacte [char_start, char_end] dans le corpus
- Probabilité prédiction
- Texte du token

Exemple (Token #1234):
──────────────────────
predictions[1234] = 1
offsets[1234] = [746, 752]
probabilities[1234] = 0.9797
tokens[1234] = "أخبرنا"

Résultat:
  {char_start: 746, char_end: 752, prob: 0.9797, token: "أخبرنا"}

Vérification:
  corpus[746:752] = "أخبرنا" ✓

4️⃣  ÉTAPE 4: IDENTIFIER LES ISNADS DÉTECTÉS (CLUSTERING)
═══════════════════════════════════════════════════════════════════════════════

Principe:
──────────
Les boundary tokens d'un même isnad sont généralement consécutifs (séparés de
quelques caractères seulement). On les groupe en "clusters" où chaque cluster
représente un isnad candidate détecté par CAMeL-BERT.

Algorithm:
──────────
Trier les boundary tokens par char_start.

Pour chaque token, décider s'il:
  A) Étend le cluster courant
  B) Commence un nouveau cluster

Critère: gap = position[i].char_start - position[i-1].char_end
  Si gap ≤ 50 chars:
    Ajouter au cluster courant
  Sinon:
    Fermer le cluster courant
    Démarrer un nouveau cluster

Résultat:
──────────
Chaque cluster = {
  cluster_id,
  cluster_start,    ← position du premier token du cluster
  cluster_end,      ← position du dernier token + longueur
  token_count,
  tokens[]
}

Exemple:
────────
Tokens: (position char_start)
  Token A: "أخبرنا"      @ 746
  Token B: "أبو"         @ 752  (gap = 752-752 = 0 ≤ 50 → cluster 1)
  Token C: "بكر"         @ 759  (gap = 759-759 = 0 ≤ 50 → cluster 1)
  Token D: "محمد"        @ 768  (gap = 768-768 = 0 ≤ 50 → cluster 1)
  Token E: "..."         @ 1200 (gap = 1200-800 = 400 > 50 → cluster 2)

Clusters:
  Cluster 1: [746, 800]   avec tokens [A, B, C, D]
  Cluster 2: [1200, ...]  avec tokens [E, ...]

Résultat Final:
────────────────
520 clusters créés (= 520 isnads détectés par CAMeL-BERT)

5️⃣  ÉTAPE 5: COMPARER POSITIONS GOLD vs CAMELBERT
═══════════════════════════════════════════════════════════════════════════════

Pour chaque isnad du gold standard:
──────────────────────────────────

1. Trouver le cluster CAMeL-BERT le plus proche:

   Pour chaque cluster:
     overlap = calculate_overlap(
       isnad_start, isnad_end,
       cluster_start, cluster_end
     )

   Choisir cluster avec overlap % maximal

2. Calculer le pourcentage d'overlap:

   overlap_start = max(isnad_start, cluster_start)
   overlap_end = min(isnad_end, cluster_end)

   Si overlap_start >= overlap_end:
     overlap_percent = 0
   Sinon:
     overlap_percent = (overlap_end - overlap_start) / (isnad_end - isnad_start) × 100

3. Calculer la distance entre débuts:

   distance = abs(cluster_start - isnad_start)

Exemple:
────────
Isnad Gold #2:
  isnad_start = 723
  isnad_end = 987

Cluster CAMeL-BERT #1:
  cluster_start = 723
  cluster_end = 987

Calcul overlap:
  overlap_start = max(723, 723) = 723
  overlap_end = min(987, 987) = 987
  overlap = (987 - 723) / (987 - 723) × 100 = 100%

Distance = abs(723 - 723) = 0 chars

Résultat: PERFECT MATCH (100% overlap, 0 chars distance) ✅
